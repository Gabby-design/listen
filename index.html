💻 Run Desktop App on Windows / macOS

1

Clone Repository

Clone the source repository from GitHub to your computer:

git clone https://github.com/Gabby-design/listen.git
2

Install Packages

Install the Electron dependencies:

npm install
3

Launch Desktop App

Start the app in your system tray:

npm start
✨

Frameless, non-focusable floating pill indicator stays on top without stealing your active cursor or window focus.

Automated Paste Injection
